# DrivX Protocol

> Driver-owned protocol. Fixed supply. Real revenue to stakers. No emissions, no inflation. 70% of all fees go to safe drivers. Built on Base.

---

## What is DrivX?

DrivX turns safe driving into a verifiable on-chain identity. Drivers build a Safety Score (0–1000) from verified trip data, own their Driving Identity on Base (Ethereum L2), and earn real revenue — in WETH and USDC — from insurers, businesses, and platforms that pay to access verified driver data.

**The thesis:** Behavioral data belongs to the person who generates it. On-chain identity is the only infrastructure that makes data ownership enforceable, portable, and monetizable.

## Key Properties

| Property | Detail |
|----------|--------|
| Token | $DVX on Base |
| Supply | 100,000,000,000 (fixed, no mint function) |
| Launch | 100% into Uniswap V4 LP via Bankr Bot |
| Liquidity | Locked permanently by Doppler Protocol |
| Revenue Split | 70% drivers / 20% protocol / 10% incentive — immutable |
| Staking Yield | Real revenue (WETH + USDC), not emissions |
| Team Tokens | 0% — team funded from treasury only |
